## [ 주요 기능 ]
- 돌리트랙 시네머신 연출

- 상속을 통한 다형성 적 설계
- Grid 분할 영역 스폰 시스템
- 터레인 활용 맵 디자인
- 서페이스 셰이더, 멀티 텍스처를 활용한 셰이더 커스텀
- Navmesh AI를 통한 적들 경로 순찰
- bounds방식의 감지 계산

### 지역 기반 적 생성 시스
맵 전체를 일정한 크기의 격자(Grid)로 분할하여 적을 배치하는 영역 기반 스폰 시스템을 구현했습니다.


-  구조
Map
 ├── Cell (0,0)
 ├── Cell (0,1)
 ├── Cell (0,2)
 ├── ...
 └── Cell (N,M)


- 핵심 구현
Mesh Vertex 기반 맵 크기 계산
Grid(Cell) 단위 영역 분할
Cell 중심 좌표 자동 계산
영역별 적 생성


- 기대 효과
하드코딩된 위치 배치 제거
스테이지 변경 시 자동 대응
대규모 맵에서도 관리 용이


## [ 도전과 고민 ]
해당 내용들은 구현에 외부적으로 도전했지만 당시 발표기간 스캐쥴로 프로젝트에 삽입하진 못했습니다.
- 어드레서블 파이어 베이스 연동 시스템 구축
- 스크립터블 오브젝트의 관리
- 제네릭 활용 파싱 데이터 연계
- BT 활용 패턴 관리
- 무한 스크롤 인벤토리 및 지도
- CSV파일 데이터 파싱 NPC 다이얼로그 관리


공부했지만 아쉽게 반영하지 못했던 기능들을 다른 프로젝트에 꼭 넣어볼 생각입니다.
