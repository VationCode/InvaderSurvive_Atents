# InvaderSuvrvie_Antents
## [ 프로젝트 개요 ]
- TPS + RPG 요소를 결합한 루터슈터장르를 목표로한 프로젝트
- 국비지원 6개월 장기 학습 프로그램에서 개발하였던 프로젝트
- 비록 팀진행에서 개별진행으로 변경하게 되었지만 유일하게 마지막날 발표한 팀입니다(각 다른 작품들로)
